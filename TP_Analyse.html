1. Présentation des données

Le jeu de données TitanicSurvival, disponible dans le package carData, décrit les passagers du Titanic selon leur survie, leur sexe, leur âge et leur classe.

library(carData)
data("TitanicSurvival", package = "carData")

Variables étudiées

  • survived : survie du passager (yes ou no).
  • sex : sexe du passager (female ou male).
  • age : âge en années.
  • passengerClass : classe du passager (1st, 2nd ou 3rd).

3. Survie selon le sexe

library(ggplot2)

ggplot(TitanicSurvival, aes(x = sex, fill = survived)) +
  geom_bar(position = "fill") +
  scale_y_continuous(labels = function(x) paste0(x * 100, "%")) +
  scale_x_discrete(labels = c(female = "Femmes", male = "Hommes")) +
  scale_fill_manual(
    values = c(no = "#E07A5F", yes = "#3D9970"),
    labels = c(no = "Non-survivants", yes = "Survivants")
  ) +
  labs(
    title = "Répartition de la survie selon le sexe",
    x = "Sexe",
    y = "Pourcentage dans chaque groupe",
    fill = "Survie"
  ) +
  theme_minimal()

Taux de survie selon le sexe

round(
  100 * prop.table(
    table(TitanicSurvival$sex, TitanicSurvival$survived),
    margin = 1
  ),
  1
)
##         
##            no  yes
##   female 27.3 72.7
##   male   80.9 19.1

Interprétation

La proportion de survivants est plus élevée chez les femmes que chez les hommes. Les pourcentages sont calculés au sein de chaque sexe, ce qui permet de comparer les groupes malgré leurs effectifs différents. Cette comparaison décrit une association entre le sexe et la survie, sans tenir compte de l’âge ni de la classe des passagers.

5. Âge selon la survie

Les 263 passagers dont l’âge est manquant sont exclus de cette analyse.

donnees_age <- subset(TitanicSurvival, !is.na(age))

ggplot(donnees_age, aes(x = survived, y = age, fill = survived)) +
  geom_boxplot() +
  scale_x_discrete(
    labels = c(no = "Non-survivants", yes = "Survivants")
  ) +
  scale_fill_manual(
    values = c(no = "#E07A5F", yes = "#3D9970")
  ) +
  labs(
    title = "Distribution de l'âge selon la survie",
    x = "Survie",
    y = "Âge (années)"
  ) +
  theme_minimal() +
  theme(legend.position = "none")

Statistiques d’âge par groupe

aggregate(
  age ~ survived,
  data = donnees_age,
  FUN = function(x) c(
    effectif = length(x),
    moyenne = mean(x),
    mediane = median(x),
    ecart_type = sd(x)
  )
)
##   survived age.effectif age.moyenne age.mediane age.ecart_type
## 1       no    619.00000    30.54537    28.00000       13.92254
## 2      yes    427.00000    28.91823    28.00000       15.06148

Interprétation

Les boîtes à moustaches permettent de comparer la médiane et la dispersion des âges entre survivants et non-survivants. Le trait à l’intérieur de chaque boîte représente la médiane ; la boîte contient les 50 % centraux des âges.

Les distributions se chevauchent : l’âge seul ne permet donc pas de distinguer clairement les survivants des non-survivants. Cette analyse porte uniquement sur les passagers dont l’âge est connu. Les valeurs manquantes peuvent limiter la représentativité des résultats.

6. Utilisation du package TitanicPackage

library(TitanicPackage)

taux_survie(TitanicSurvival, "sex")
##   groupe taux_survie_pct
## 1 female            72.7
## 2   male            19.1
taux_survie(TitanicSurvival, "passengerClass")
##   groupe taux_survie_pct
## 1    1st            61.9
## 2    2nd            43.0
## 3    3rd            25.5

Le taux de survie est de 72,7 % chez les femmes et de 19,1 % chez les hommes. Il est de 61,9 % en première classe, 43,0 % en deuxième classe et 25,5 % en troisième classe.

Ces comparaisons sont descriptives : elles ne permettent pas d’isoler l’effet propre du sexe, de la classe ou de l’âge.
